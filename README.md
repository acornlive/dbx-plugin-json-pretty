# JSON 格式化工具 · DBX 插件

在 DBX 工作台内格式化、压缩、折叠、转义 JSON 的全能工具。数据全在本机处理，不上传网络。支持超大文件分块读写、拖放导入、工作区文件树管理。

## 功能

- **格式化**：输入自动美化（2 空格缩进），右侧生成可折叠的语法高亮树
- **压缩**：输出单行紧凑 JSON
- **转义 / 去转义**：JSON 与字符串字面量互转
- **虚拟滚动**：结果区 DOM 行数恒定，大数据量依然流畅；子节点分页按需加载
- **层级展开**：按深度生成 1~10 级按钮，大内容智能估算行数自动折叠
- **复制**：左右两侧标题栏复制按钮 + 右键菜单复制所选
- **工作区**：左侧文件树管理（新建 / 重命名 / 移动 / 删除文件夹和文件），开启「保存」后编辑内容自动写回文件


## 兼容性

| 项目 | 要求 |
| --- | --- |
| DBX 版本 | ≥ 0.6.23 |
| Host API | ^1.3 |
| 权限 | `host.clipboard:read`、`host.filesystem` |
